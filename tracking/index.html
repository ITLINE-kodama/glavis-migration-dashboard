GLAVIS GROUP / SITE MIGRATION 計測タグ 確認マニュアル

移行後のサイトに、現在お使いのアクセス解析・広告計測のタグを引き継ぎます。 現行サイトに設置されているタグをご確認のうえ、ページ下部のフォームからお送りください。

期限2026年8月21日

対象HD・GA・採用

なぜ必要か

タグが引き継がれないまま公開すると、公開日を境にアクセスデータが途切れ、 Web 広告のコンバージョン計測も停止します。 過去との比較ができなくなり、広告の効果測定にも影響が出ますので、 公開前の受領をお願いしております。

全部は分からない、という状態でも問題ありません。 分かる範囲でお送りいただければ、残りは ITLINE 側でも現行サイトを確認いたします。

確認方法

下記のいずれかの方法でご確認いただけます。 方法1が最も確実ですが、管理画面をお使いの場合は方法2・3が簡単です。

  1. サイトのソースから探す（最も確実）

    対象サイトをブラウザで開き、Ctrl + U （Mac は ⌘ + option + U）でソースを表示します。 続いて Ctrl + F で下記の文字列を検索してください。

    検索する文字列見つかるもの形式
    G-GA4 測定 IDG-XXXXXXXXXX
    GTM-Google タグマネージャーGTM-XXXXXXX
    AW-Google 広告のコンバージョンAW-XXXXXXXXX
    UA-旧アナリティクス（参考）UA-XXXXXXX-X
    google-site-verificationSearch Console 所有権確認meta タグ
    yjtag / yahooYahoo! 広告タグ—
    uetq / bat.bingMicrosoft 広告（UET タグ）—

    見つかった行をそのままコピーしてお送りいただいて構いません。 ID だけ抜き出していただく必要はありません。

  2. Google アナリティクスの管理画面から確認する

    analytics.google.com にログインし、左下の「管理」→「データストリーム」→対象のストリームを開くと、 右上に測定 ID（G- から始まる文字列）が表示されます。

    サイトごとにストリームが分かれている場合は、それぞれの測定 ID をご確認ください。

  3. Google タグマネージャーの管理画面から確認する

    tagmanager.google.com にログインすると、画面上部にコンテナ ID（GTM- から始まる文字列）が表示されます。

    タグマネージャーをご利用の場合、個別の広告タグはこの中で管理されていることが多く、 コンテナ ID のご共有だけで足りる場合があります。

  4. 管理画面への権限付与でも対応できます

    ID をお調べいただく代わりに、Google アナリティクス／タグマネージャーの管理画面から ITLINE のアカウントを招待いただく方法でも対応可能です。 その場合は招待先のアカウントを別途ご案内いたしますので、 下のフォームの「連絡事項」にその旨をご記入ください。

  5. Web 広告のタグについて

    採用サイトの URL を広告のランディングページに使用されているとのことでしたので、 広告側の計測タグもあわせてご確認ください。代理店にご依頼されている場合は、 「移行に伴いタグの引き継ぎが必要」とお伝えいただければ、 先方から必要な情報をご提供いただけます。

このあとの流れ

  • ITLINE にて、移行後の各サイトへタグを設置します。

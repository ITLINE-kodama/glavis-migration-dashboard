GLAVIS GROUP / SITE MIGRATION 計測タグの引き継ぎについて

移行後のサイトでも、現在のアクセス解析と広告計測をそのまま継続できるようにいたします。 現行サイトは ITLINE にて調査済みですので、ご対応いただくのは 1 点のみです。

ITLINE にて確認済みの内容

3 サイトの HTML ソースを確認したところ、いずれも Google タグマネージャー（GTM）経由でタグを読み込む構成でした。 読み込まれているコンテナは下記のとおりです。

サイトGTM コンテナ
ホールディングス GTM-MTQ27JHK　GTM-PR2QHTL
グラビス・アーキテクツ GTM-MTQ27JHK　GTM-WLJ4JZX
採用サイト GTM-MTQ27JHK　GTM-PR2QHTL

GTM-MTQ27JHK は 3 サイト共通で読み込まれており、 グループ全体用のコンテナと思われます。コンテナ ID は判明しておりますので、 これらをお調べいただく必要はございません。

GA4 の測定 ID や広告のコンバージョンタグは、この GTM コンテナの中で管理されています。 サイトの HTML ソースには現れないため、中身を確認させていただく必要がございます。

ご対応いただきたいこと

下記のいずれか 1 つで結構です。A が最も簡単で、確実です。

A GTM に ITLINE を招待する 2分

GTM の管理画面で、ITLINE のアカウントに閲覧権限を付与いただきます。 中身をこちらで確認できるため、以降のやりとりが不要になります。

  1. tagmanager.google.com を開く
  2. 対象のコンテナを開き、上部の「管理」タブへ
  3. 「ユーザー管理」→ 右上の「＋」→「ユーザーを追加」
  4. ITLINE のアカウントを入力し、コンテナの権限を「閲覧」にして招待

招待先のアカウントは ITLINE より Teams にてご案内いたします。 下のフォームで A をお選びいただければ、こちらからお送りします。

B コンテナをエクスポートして送る 3分

設定内容をファイルに書き出してお送りいただく方法です。 アカウントのご準備や招待の手続きが不要です。

  1. GTM で対象のコンテナを開き、上部の「管理」タブへ
  2. 「コンテナをエクスポート」をクリック
  3. 公開中のバージョンを選び、「エクスポート」で JSON ファイルを保存
  4. Teams でファイルをお送りください
C GA4 の測定 ID を調べて送る 5分

A・B が難しい場合の方法です。GTM の中から測定 ID を確認していただきます。

  1. GTM で対象のコンテナを開き、左メニューの「タグ」へ
  2. 一覧から「Google タグ」または「GA4 設定」のタグを開く
  3. 測定 ID（G- から始まる文字列）を控える
  4. 下のフォームでご入力ください

タグ一覧の画面をスクリーンショットでお送りいただく形でも結構です。 その場合はフォームの「連絡事項」にその旨をご記入ください。

ご連絡フォーム

ひと手間おかけする理由 計測タグには広告アカウントに紐づく情報が含まれるため、外部のフォーム送信サービスを 経由させない設計にしております。このページは入力内容からメール本文を組み立てるだけで、 どこかへ自動的に送信したり、サーバーに保存したりすることは一切ありません。 お手数ではございますが、セキュリティ上あえて、お客様ご自身のメールソフトから 直接お送りいただく形にしております。

このあとの流れ

  • ITLINE にて GTM の設定内容を確認し、移行後の各サイトに同じ構成でタグを設置します。
  • 公開前のテスト環境で、タグが正しく発火することを確認します。
  • 公開後、Search Console に新しい URL を登録し、サイトマップを送信します。
  • 採用サイトは URL が変わるため、広告のランディングページ設定の更新が必要になる場合があります。 必要な対応が判明しましたら、ITLINE よりご連絡いたします。

ご不明な点は Teams、またはお電話にて遠慮なくお問い合わせください。

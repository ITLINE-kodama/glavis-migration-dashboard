GLAVIS GROUP / SITE MIGRATION 採用サイトURL 遷移先のご回答（301リダイレクト）

9月末の公開で、採用サイトは glavis-hd.com/recruit/ga/ から glavisarchitects.com/recruit/ へ移設されます。 旧URLにアクセスした方を新しいページへ自動転送（301リダイレクト）するため、 転送先の一覧をご確認いただき、変更したいページだけご指定ください。

ご対応いただく方グラビス様（守口様）
期限2026年9月5日（金）
所要時間10分程度
対象採用サイト 全60ページ

ご負担を最小にする設計にしています

  • 全60ページの転送先は、ITLINE にてすでに機械的に割り当て済みです。 「どこへ飛ばすか」を1件ずつご記入いただく必要はありません。
  • ご確認いただくのは 「この転送先で問題ないか」だけです。 問題のない行は何もせず、例外の行だけプルダウンでご指定ください。
  • すべて案の通りでよければ、その旨をメールにご記入いただくだけでも結構です （シートの返送は不要です）。

ご回答の手順（3ステップ）

  1. ご回答シート（Excel）をダウンロードする

    下のボタンから、転送先一覧入りのExcelをダウンロードしてください。

    ご回答シートをダウンロード（Excel・60件）

    1シート目に記入方法、2シート目にURL一覧が入っています。

  2. 例外の行だけ「ご回答」列を変更する

    F列（薄黄色）のプルダウンからお選びください。初期値は「案の通りでOK」です。

    案の通りでOK そのままで結構です（初期値）。何も操作は要りません。
    変更したい（G列にご記入） 転送先を変えたい場合。G列に転送先URLをご記入ください。
    このページは廃止（採用トップへ） 新サイトに残さないページ。採用トップまたは求人一覧へ転送します。

    特にご確認いただきたい点 Web広告のリンク先（LP）に採用サイトのURLをお使いの場合は、 該当行の転送先を優先的にご確認ください。あわせて広告代理店への連絡要否のご判断も お願いしております（タスク T-32）。

    下のボタンを押すと、宛先・件名の入ったメールが立ち上がります。 ご記入済みのExcelを添付のうえ、ご送信ください。

    メールを作成する（Excelを添付してください）

    Teams のプライベートチャットへの添付でも結構です。
    送信先：tsutomu.kado@mocamoco.com（加堂）／ kodama@itline.co.jp（小玉）

このあとの流れ

  • ご回答をもとに、ITLINE にて301リダイレクトを設計・設定します（9月20日まで）。
  • リダイレクトは一時的なものではなく、恒久的に維持します。 検索結果・ブックマーク・広告など、どこから旧URLへアクセスしても新しいページへ届きます。
  • 公開後、Search Console にて転送の反映と検索結果の引き継ぎを確認します。

よくいただくご質問

Excelの操作が難しい・時間が取れない
「すべて案の通りでOK」の一言をメールまたはTeamsでいただくだけでも結構です。 個別のご相談はお打ち合わせでも承ります。
検索結果からの流入は減りませんか？
301リダイレクトは検索エンジンに「引っ越し先」を正しく伝える標準的な方法で、 評価は新URLへ引き継がれます。移設直後に一時的な変動が出ることはありますが、 Search Console で経過を確認します。
求人ページは今後増減します。その都度回答が必要ですか？
いいえ。今回のご回答は移設時点の全ページ分で完結します。 移設後の新規ページは最初から新URLで作成されるため、リダイレクトは不要です。
QRコード付きの印刷物・パンフレットに旧URLを載せています
リダイレクトにより印刷物のQR・URLもそのまま使えます。刷り直しは不要です。
